A simple console-based Library Management System built in Java. It lets you add, view, search, issue, return, and delete books using an interactive text menu.

Features:-
1. Add Book — Register a new book with a unique ID, title, and author.
2. Display Books — View all books currently in the library in a formatted table.
3. Search Book — Look up a book by its ID.
4. Issue Book — Mark a book as issued (borrowed).
5. Return Book — Mark an issued book as returned.
6. Delete Book — Remove a book from the library by ID.
7. Input validation — Invalid menu choices and non-numeric IDs are caught gracefully; the program never crashes on bad input and simply re-prompts.
8. Duplicate prevention — Books with an already-existing ID cannot be added.
